# 2024吉林省电子设计大赛D题 - 可控四轮变距小车系统

## 项目简介
本项目为2024年吉林省大学生电子设计竞赛D题蓝牙控制的解决方案，实现基于Android蓝牙控制的四轮独立变距智能小车系统。包含完整的Android控制端源码、硬件驱动逻辑、运动控制算法以及最终提交的技术论文。

## 系统组成
### 硬件部分
- STM32F4主控板
- L298N电机驱动模块
- HC-05蓝牙模块
- 3D打印定制化车体结构
- 四路步进电机系统

### 软件功能
#### Android控制端
- 蓝牙4.0 BLE连接管理
- 实时运动控制界面（前进/后退/转向）
- 轮距参数可视化设置

#### 嵌入式系统
- 四轮独立PID控制算法
- 蓝牙指令解析器
- 运动学模型解算
- 安全保护机制（过流/过压/堵转检测）

## 使用说明
1. 硬件连接：
   ```bash
   手机蓝牙 -> HC-05模块 -> STM32主控 -> L298N驱动 -> 步进电机组
   ```

2. 操作流程：
   - 打开小车电源开关
   - 启动Android应用扫描蓝牙设备
   - 配对"VARIABLE_TRACK_CAR"设备
   - 进入控制界面操作

1. 首次使用需完成蓝牙配对
2. 建议保持设备在10米有效范围内
